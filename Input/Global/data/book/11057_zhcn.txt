^4D4DFF简单易做的手工巧克力^000000

^46BEFF--------------------------------------------------------------------------------------^000000
准备：制作白巧克力时需白巧克力5个，「ID:T008307」1个
制作黑巧克力时需巧克力5个，「ID:T008307」1个
^46BEFF--------------------------------------------------------------------------------------^000000

制作方法
送礼用手工巧克力的基础是将基础的可可脂巧克力用隔水加热融化后，
按照自己喜欢的形状凝固，是简单又基础的巧克力甜点。

1. 将巧克力切碎或捣碎，便于融化。
2. 保持适当温度，用隔水加热法融化巧克力。
3. 融化的巧克力取一部分出来，加入牛奶搅拌成柔滑的奶油状。
4. 剩下的巧克力倒入喜欢形状的模具中，冷却至完全凝固。
5. 将凝固的巧克力从模具中取出后，涂抹第3步做好的巧克力奶油，按个人喜好装饰。
*也可以混入切碎的坚果，像做topping一样涂在上面。

^CD3278酸甜可爱的「ID:T008262」巧克力^000000

^46BEFF--------------------------------------------------------------------------------------^000000
准备：新鲜草莓2个，巧克力1个，白巧克力1个

^46BEFF--------------------------------------------------------------------------------------^000000

制作方法
用隔水加热融化的巧克力包裹新鲜草莓表面，是可爱又酸甜的巧克力甜点。
如果不注意草莓的水分，巧克力包裹会不容易成功，需要注意。

1. 将巧克力切碎后用隔水加热融化。
2. 抓住「ID:T008262」的蒂部，将草莓约70%部分轻轻蘸入融化的巧克力，包裹表面。
-> 草莓表面要先去除水分，确保无水。
3. 蘸好巧克力的草莓插在签子上倒立，等待巧克力凝固。
4. 「ID:T008262」表面的巧克力完全凝固后，用融化的其他颜色巧克力装饰。

^4C1919浓郁巧克力盛宴 巧克力塔^000000

^46BEFF--------------------------------------------------------------------------------------^000000
准备：「ID:T008307」3个，鸡蛋1个，面粉1个，巧克力3个

^46BEFF--------------------------------------------------------------------------------------^000000

在烤得酥脆的塔皮中填入柔滑的巧克力甘纳许后凝固，是一道可以品尝到巧克力柔滑又浓郁口感的甜点，也很适合送礼。

1. 将室温软化的黄油与筛过的面粉和鸡蛋混合，揉成面团。
2. 用面团做成塔皮，放入180度预热的烤箱烘烤约15分钟。
3. 将巧克力切碎后用隔水加热融化。
4. 在融化的巧克力中加入牛奶，搅拌成柔滑的甘纳许状态。
5. 将第2步烤好的塔皮中填入第4步的巧克力甘纳许，冷却凝固。

[布朗尼]
^003A9D
材料：黑巧克力130g，黄油75g，鸡蛋2个，砂糖135g，少许盐（如用有盐黄油则不用加盐）
无糖可可粉15g，低筋面粉100g（普通中筋面粉也可），可根据喜好准备坚果
^000000
鸡蛋和黄油需提前放至室温。

1. 巧克力和黄油用隔水加热融化。
2. 鸡蛋打入碗中，加入盐和砂糖搅拌。
搅拌至呈现柔和的象牙色，砂糖完全溶解。

3. 将第1步倒入第2步中搅拌均匀。
4. 筛入面粉和可可粉，用刮刀轻轻搅拌。
搅拌时要轻柔，避免蛋泡消泡。
如有准备坚果，可加入面糊中混合。

将面糊倒入铺有烘焙纸的18*18cm方形模具中，轻敲两下排气，
放入预热至165~170℃的烤箱中烘烤约25分钟。
用签子插入，若带出少许面糊即为口感Q弹。

[生巧克力（生巧克力）]
^003A9D
材料：巧克力可可脂200g，鲜奶油80g，少许可可粉，黄油10g
^000000
巧克力与鲜奶油比例为2:1或3:1，可根据需要调整用量。
鲜奶油比例越高，巧克力越软越细腻。
也可减少鲜奶油用量，加入水饴。
黄油需提前放至室温。

1. 将鲜奶油用中火加热至沸腾。
2. 沸腾后关火，加入切碎的巧克力和黄油搅拌融化。
3. 将融化好的混合物倒入模具中冷却后，放入冰箱冷藏凝固。
4. 取出凝固的巧克力，切成合适大小。
5. 在可可粉中滚一圈，使其表面裹上一层可可粉。

[巧克力雪球]
^003A9D
材料：黑巧克力200g，黄油60g，砂糖70g，鸡蛋1个，低筋面粉250g
泡打粉6g，糖粉，坚果80g
^000000
1. 鸡蛋提前放至室温，打散后加入砂糖搅拌均匀。
2. 巧克力和黄油用隔水加热融化。
3. 将第2步倒入第1步中搅拌均匀。
4. 筛入面粉和泡打粉，用刮刀从上往下切拌。
刮刀一边切拌一边逆时针转动碗搅拌。
-> 这是为了防止产生过多的面筋。
5. 将准备好的坚果切碎，加入面糊中用刮刀轻轻混合。
6. 将面糊装入保鲜袋，放入冰箱冷藏约30分钟。
7. 取出面糊，分成小块搓成圆球状。
8. 将圆球间隔摆放在烤盘上，放入170~180度烤箱烘烤约15分钟。
9. 烤好的巧克力球在糖粉中滚一圈，裹上一层白色外衣。
