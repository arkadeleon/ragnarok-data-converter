^000088Objets de récompense !!^000000

Les objets que vous pouvez recevoir en récompense diffèrent selon chaque camp,
L’insigne que vous pouvez obtenir lors du combat de Tierra est l’Insigne de Bravoure(-A)
L’insigne que vous pouvez obtenir lors du combat de Flavius est l’Insigne d’Assaut(-B)
Entre parenthèses figurent le type d’insigne et la quantité requise.
S’il n’y a pas d’indication de type d’insigne, vous pouvez l’obtenir avec le même type d’insigne.
