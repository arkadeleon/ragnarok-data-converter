^FF0000特制熊掌料理 :^000000 
材料 : ^4B0082熊掌 1个, 胡萝卜 1个, 南瓜头 1个, 芦荟的叶子 1个, 
西纳雷花 的 叶片 1个, 清淡酱料 1个^000000
做法 : 将泡在水里的熊掌洗净，稍微在沸水中焯一下，
再次洗净后，在带肉的部分切“+”字刀口，然后用布包好。
放入锅中，加入水、盐、清酒、胡椒粉煮沸，撇去浮沫，
加入生姜和葱，用小火慢炖。胡萝卜和南瓜切成适口大小煮熟备用。
叶子洗净后加盐炒一半放在盘子中间，
将蒸好的熊掌从布中取出放在上面。另一半叶子放在盘子周围，
与煮熟的胡萝卜、南瓜一起装饰。煮熊掌剩下的汤
加入清淡的酱汁调味，煮至浓稠后加入香油，淋在熊掌上。
熊掌有腥味，烹饪时要注意，杂质和毛要彻底去除，
但要小心不要损伤表面，经常换水以去除异味。
特别是煮熊掌时火候的控制很重要。

^0000FF王室专用高级茶 :^000000 根据调配方法有不同的风味！
材料 : ^4B0082刺果 1个, 西纳雷花 的 叶片 1个, 世界树叶子 1个, 芦荟的叶子 1个, 
蜂王浆 1个, 黄色香料 1个^000000
做法 : 将晒干的刺果和叶子炒香后切成适当大小，
用发酵和干燥好的叶子适当调配。
想要酸味就多加些刺果，
想要苦味就多加西纳雷花叶。
在茶壶中倒入接近沸腾的热水，
小茶叶泡2~3分钟，大茶叶泡3~4分钟。
皇家果冻和黄色香料可根据个人口味增减。

^800000特制吐司 :^000000 和街头的吐司（材料）不同！
材料 : ^4B0082面包 1个, 蜂王浆 1个, 肉 1个, 草莓 1个 , 辣味酱 1个, 奶酪 1个, 甜味酱汁 1个^000000
做法 : 面包用黄油烤至金黄，肉剁碎后与辣味酱拌匀，
按面包大小厚厚地煎成肉饼。草莓做成果酱或切片备用。
在面包上抹果酱，放上肉肉饼，淋上辣味酱，
再加上奶酪即可。如果是切片的草莓，先在面包上抹辣味酱，放上肉饼，
甜味酱与皇家果冻混合后抹在上面，再加奶酪，
最后放上切片草莓，用面包盖好即可。

^008040超辣咖喱 +9 :^000000 辣到工作时都刺痛！
材料 : ^4B0082芦荟汁液 1个, 辣味酱 1个, 肉 1个, 西纳雷花 的 叶片 1个, 
南瓜头 1个, 胡萝卜 1个^000000
做法 : 将芦荟贝拉和希纳雷干燥后磨成粉备用。
肉切成2cm方块，用盐、胡椒粉等腌制。
南瓜、胡萝卜也切块，用黄油炒香。
肉和蔬菜分开炒，肉熟后与炒好的蔬菜一起
再稍微炒一下，加入适量调配好的芦荟汁液和西纳雷花粉，
炒匀后加水煮沸，收汁后加入辣味酱再煮一会即可。

^FF8040巨型包饭料理 :^000000 大到一个人吃不完的尺寸！
材料 : ^4B0082树叶衣服 1个, 肉 1个, 彩虹胡萝卜 1个, 南瓜头 1个, 清淡酱料 1个, 谷物 1个^000000
做法 : 树叶衣去掉茎部纤维后，与南瓜一起放入蒸锅蒸熟，
冷却后备用。肉去血水后用线绑好，
与南瓜、胡萝卜一起放入煮开的水中煮约40分钟。可适量加入清淡酱汁。
全熟后取出稍微冷却，切成适当大小的薄片。
谷物去壳煮饭，胡萝卜切丝稍微炒一下备用。
展开树叶，将茎放在叶子内侧，
放上米饭、肉、胡萝卜、南瓜等，抹上清淡酱汁包裹好即可。

^400080草莓饭团 :^000000 有人称之为波利味饭团。
材料 : ^4B0082草莓 1个, 谷物 1个, 树叶衣服 1个, 黄色香料 1个, 红色香料 1个, 清淡酱料 1个^000000
做法 : 谷物脱壳后煮饭，草莓榨汁备用。
将煮好的米饭放入大碗中稍微冷却，
加入清淡酱汁、香料和草莓汁拌匀。
注意不要搅拌太用力，否则米粒会碎。
揉成适当大小的饭团，用焯过的
树叶衣包裹即可。
