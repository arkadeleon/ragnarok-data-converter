#
[ 創建公會 ]
 1. 須持有華麗金屬G。 
 (可於道具商店購買華麗金數G。)
 
 2. 在持有華麗金數G的狀態下於聊天室窗輸入
 '/公會 (公會名稱)'或 
點擊'創建公會'鍵創建公會。
 
 3. 可使用ALT+G呼叫公會資訊視窗。
#
 
[ 公會資訊視窗 ] 
#
 1. 可查看公會名稱、經驗值、公會等級、公會徽章、
 公會長姓名、公會員數、公會員平均等級、
 同盟、敵對公會的資訊。
#
 
 2. 公會員資訊 : 
 可瀏覽公會員個別資訊，
 右擊可管理自己是否退出公會。. 
 僅可由本人退出公會， 
 公會長可另外將人逐出公會。
#
 
 3. 職位設定 : 
 可設定公會員的公會經驗值貢獻與職位。
 最多可貢獻50%。 
 退出公會時將重置貢獻公會的經驗值資訊。
#
 
 4. 公會技能 : 
 公會每升級1階段給予1個技能點數， 
 投資於技能時可使用公會技能。
#
 
 5. 流放者 : 
 顯示被逐出公會的名單與原因。
#
 
 6. 公會者可透過聊天室窗告知公會員各種公告事項。
 
#
 
[ 登錄與變更徽章 ]
#
 1) 以24 X 24 pixel的256色(BMP)格式製作徽章。 
#
 
 2) 在安裝RO的資料夾內新增Emblem資料夾，並複製徽章圖檔後放入。
#
 
 3) 在公會資訊視窗點擊顯示徽章處的編輯鍵，即可套用徽章。
#
 
 4) 僅公會長可變更徽章，並可隨時變更。
#
