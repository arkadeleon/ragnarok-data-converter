#
[ 创建公会 ]
 1. 需要持有华丽金属。 
 (华丽金属可在商城进行购买。)
 
 2. 在持有华丽金属的状态下在聊天窗口 
 输入'/公会 (公会名)'或者 
 点击'创建公会'图标来进行创建公会。
 
 3. 通过ALT+G可打开公会信息窗口。
#
 
[ 公会信息 ] 
#
 1. 公会名, 经验值, 工会等级, 公会徽标, 
 会长名字, 成员数, 成员平均等级
 , 同盟, 敌对公会信息都可以确认到。
#
 
 2. 成员信息 : 
 可查看公会成员的个人信息,
 右击可选择退出公会。 
 退出公会只能自己来进行操作, 
 或者通过公会长进行强制踢出来进行。
#
 
 3. 职位设定 : 
 公会成员可缴纳公会经验值及职位设定，
 缴纳最高可缴纳50%。 
 在公会缴纳的经验值信息在退出工会时 
 一键初始化。
#
 
 4. 公会技能 : 
 公会每升1级可获得1点技能点 
 投资该点可使用
 公会技能。
#
 
 5. 逐出者 : 
 显示在公会被逐出的人员名单和 
 逐出理由。
#
 
 6. 公会会长通过聊天窗口向公会员传递
 各种重要公告。
#
 
[ 图标登陆及变更 ]
#
 1) 24 X 24 pixel大小的256色BMP格式图片 
 可设定为公会徽标。
#
 
 2) 在安装仙境传说的文件里创建Emblem文件 
 在该文件里复制徽标文件。
#
 
 3) 在公会信息窗口上点击徽标 
 选择编辑可适用自选的徽标。
#
 
 4) 徽标只有公会徽章才能更改， 
 并且可以随时更改。
#
