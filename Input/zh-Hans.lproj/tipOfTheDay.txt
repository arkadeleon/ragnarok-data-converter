→/savechat  :  把对话窗口的内容保存起来
#
→按住ctrl键，再按*键，可切换小地图透明度 
#
→按住shift键，再按鼠标右键拖曳，可以把视角的角度抬高，如要恢复原状，按住shift键，再按两次鼠标右键，即可恢复 
#
→按住ctrl键，再按鼠标右键拖曳，可以把视角放大缩小，这时按住ctrl键，再按两次鼠标右键，即可恢复原状，用鼠标滚轮也可以把画面放大缩小
#
→把光标放在敌人身上时，游标会变成刀， 既可攻击
#
→打魔物获得的经验值，与怪物受到的损害值同正比※一起给攻击怪物时，先攻击怪物的人，得到的经验值较多
#
→按住ctrl键攻击魔物时，会变成[锁定攻击状态]，将会持续自动攻击到魔物死亡为止，想要解除自动攻击状态时，将鼠标光标点选其他位置既可
#
→想要捡掉下来的物品，把光标指在物品上再[点选鼠标左键]即可，捡到的物品会放在物品栏里
#
→把光标移到物品身上[点选鼠标右键]时，可以看到物品的情报
#
→人物角色脚底下二个横杠是玩家的HP值和SP值，绿色的表示HP值，蓝色的表示SP值，HP值到0时，表示玩家已死亡，当HP值剩下25%以下时，HP值会改变成显示为红色
#
→EXP显示杆已满的话(100%)，基础等级会上升，基础等级上升时，会获得素质点数（Status Point），玩家可自由加给于想加强的属性
#
→EXP 表示杆下面的JOBEXP显示杆已满的话(100%)， 职业等级会上升，会获得技能点数，技能点可用于学习和强化技能
#
→若玩家原地不动时，HP和SP会稍微恢复※坐着时会恢复速度会加快两倍，而当重量超过50%以上时，将不会恢复HP值与SP值
#
→Weight(重量) : 显示为最大负重量和负重量，玩家无法携带超过最大负重量的物品，物品重量超过最大负重量时，将不能携带任何物品。若携带的物品重量超过最大负重量一半时限度超过一半时，将会显示为红色，这时HP和SP不会自动恢复，还有超过最大负重量90%时，玩家将不能攻击和使用技能
#
→Zeny(金币) : 金币是在仙境传说里所使用的[金钱]单位 ※玩家所拥有的金币当交易或购买物品时会自动扣减
#
→基础等级上升后，会得到素质点数（Status Point）， 玩家可利用素质点数强化自身属性
#
→STR(力量) : 力量增加时，可提升负重和物理近战的攻击力
#
→DEX(灵巧) : 灵巧增加时，可提升命中率和施放魔法的速度，也会提升使用弓箭的攻击力
#
→AGI(敏捷) : 敏捷增加时，可提升回避率，可闪躲敌人的攻击，并提升武器的攻击速度
#
→VIT(体质) : 体质增加时，可提升最大HP值、HP恢复速度、物理防御力
#
→INT(智力) : 智力增加时，可提升MP最大值、魔法攻击力、魔法防御力
#
→LUK(幸运) : 幸运增加时，可提升必杀攻击率和完全回避率
#
→[Print Screen] or [Scroll Lock] : 拍照，照片会在[ScreenShot] 文件夹内保存起来
#
→[F10] : 可以调整聊天窗口大小
#
→[F11] : 只保留基本信息窗口和对话窗口，关闭其他窗口
#
→[F12] : 可以开启/关闭动作条  ※将经常使用的物品或是技能拖曳于在F1～F9键上，直接按所属快捷键就可以使用
#
→[INSERT] :将可坐下或站立  ※将[/坐下]或是[/站立]这两个指令直接输入于对话窗就可以使用。在坐下的状态时HP、SP回复速度比站立时加快两倍
#
→[Alt] + [End] : 可以把角色下方 [HP / SP] 图示开启/关闭
#
→[Alt] + [Home] : 可以把可移动的地区图示开启/关闭
#
→[Alt] + [=] : 切换输入状态，全角转半角。用全角输入的命令不会执行 这时候切换成半角输入即可
#
→[Alt] + [F10] : 可以把聊天窗口开启/关闭
#
→[Alt] + [1~9] , [Ctrl] + [-,=,w] :[Alt] + [1~9] 可以使用出以下图释︰惊叹号、问号、音符、爱心、汗滴、灵感灯泡、怒气青筋、乌云、金钱、无言点点。[Ctrl] + [-,=,w]︰ 剪刀、石头、布 
#
→/WHO : 可以看到服务器上， 在线玩家总人数
#
→/WHERE : 可以看到现在所在位置的情报和坐标
#
→/H : 显示对基本的指令说明
#
→/BGM : 可以把背景音乐开启/关闭  ※也可以按 [Alt] + [0] 在窗口上执行
#
→/SOUND : 可以把效果音开启/关闭   ※也可以按 [Alt] + [0] 在窗口上执行
#
→/EFFECT : 可以把游戏里的各种效果图示开启/关闭   ※关闭效果时，可以使游戏执行上更加顺畅
#
→/SKIP :开启/关闭画面同步更新
#
→/EX  【角色名称】:  可以隔绝此玩家所说的话和悄悄话
→/IN 【角色名称】:  恢复与此玩家之间的对话
#
→/EXALL : 把所有角色的对话屏蔽
→/INALL : 恢复与所有玩家对话
#
→/EX : 显示被屏蔽玩家的清单
#
→/ORGANIZE 【队伍名称】: 可组成队伍  ※如是队长时，可以邀请玩家参加组队
#
→把光标放在想邀请的玩家身上， 点选鼠标右键，会显示 ' 邀请参加组队 ' 选项，利用这选项，可组成队伍  
#
→/LEAVE : 可以脱离自己参加的队伍  ※打了此项指令后，将不会询问同意与否
#
→/EXPEL 【角色名称】: 队长可将队员于队伍中剔除※打了此项指令后，将不会询问同意与否
#
→点选对话窗口右下段 [圆圈]后，将会显示〝队伍发言频道〞，点选后将可使用队伍频道与队员对谈
#
→%  : 在发言前加上%既可直接使用队伍频道与队员对谈，或是按住Ctrl键，再按Enter键，把输入的内容直接传达给队员  
#
→队员右上方微型地图将会显示各队员所在位置
#
→悄悄话 : 聊天窗口左边输入角色名称，右边输入对话内容 ，用TAB键将可快速于二个输入栏里转换位置
#
→选择微型地图 [+ / -] 符号时，地图将会 [放大 / 缩小]

→[MVP系统] : 与Boss级魔物对决时，为了保护最高伤害者的权益，魔物的MVP物品将会直接掉落于MVP玩家，如魔物未掉落MVP物品，将补偿玩家50%的经验值 
#
→游戏在窗口模式进行时，可以移动窗口位置，按住[Alt] + [空格键]再按[m]键，可用箭头键或是鼠标调整位置
#
→/fog : 可以把雾化效果开启/关闭，雾化效果是为各种地图做天气表现使用，对低阶计算机配备玩家来说，雾化效果会增加计算机负担，玩家如被迫跳出或停止游戏时，这时建议玩家关掉雾化效果，雾化效果也可组态设定下永久开启或是永久关闭
#
→从魔物获得的物品、不能确认物品的效果，可用道具商店所贩卖的放大镜来确认物品的效果
#
→猎人若要用陷阱系列技能，身上必须《携带装置用陷阱物品》
#
→组成工会需要消耗一个华丽金属，组成工会指令为  /GUILD  [工会名字] ,工会名字不可有特殊字符与空白用，Alt +G 可以打开工会窗口
#
→工会会员之间对谈可使用/GC 【对话内容】 或是 $ 【对话内容】 或是按 Alt + Enter 也可以
#
→若想使装备附属卡片，请先卸下所想附属的装备，对卡片点选两下将会出现可附属物品清单，再点选所想附属之物品既可
#

--黑暗 : 画面变黑暗，对怪物来说视线会变狭碍
--冰冻 : 将无法行动，当受到攻击时，才会解除此状态
